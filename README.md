# Socheat Rotanak

I write Windows software that stays on your machine.

Most of it is Rust. Download managers, game-library compression, DNS tools. I care about the boring parts: installers that register native hosts correctly, queues that resume, resolvers that fail over.

I'm a second-year Digital Technologies student at AUPP in Phnom Penh. Coursework leans cybersecurity and networking. Side projects lean desktop apps, because that's what I actually run day to day.

## Projects

**[RusticDL](https://github.com/JustNak/RusticDL)**
Local-first HTTP(S) download manager. Rust and [GPUI](https://gpui.rs/). Optional browser handoff for Chrome, Edge, and Firefox. No accounts, no telemetry.

**[RusticGU](https://github.com/JustNak/RusticGU)**
Compact a Steam library with transparent WOF compression so games stay playable. Live Compact after patches.

**[DNS Bench Pro](https://dnsbenchpro.netlify.app)** · [source](https://github.com/JustNak/DNSBenchPro)
Browser-only DoH benchmark. It measures public resolvers from your network and does not log your IP or results.
